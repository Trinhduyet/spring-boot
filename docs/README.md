# Learning documentation map

Start here: [Hướng dẫn cấu trúc dự án, Java core, Spring và annotations](huong-dan-java-spring.md). The Vietnamese guide follows the Product request through the actual source and compares Java/Spring with .NET.

| Path | Purpose |
|---|---|
| `architecture/` | Package-by-feature structure, request flow, and database model |
| `java-core/` | Java 21 language, collections, streams, errors, generics, concurrency, JVM |
| `spring-core/` | IoC/DI, bean scopes/lifecycle, auto-configuration, AOP proxies |
| `spring-mvc/` | REST controllers, lifecycle, validation, errors |
| `spring-data/` | JPA, Hibernate, persistence context, relationships, queries, transactions |
| `dotnet-to-java/` | Paired Java/.NET examples and the 14-day path |
| `database/` | SQL Server development setup, schema safety, JPA mapping |
| `development/` | Local setup, debugging, and test workflows |

Documents should connect concept, code, C# comparison, pitfalls, practice, and source links. The current code is in `src/main/java/com/example/catalog`; test profile is `src/main/resources/application-test.yml`.
